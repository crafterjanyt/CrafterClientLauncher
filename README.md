CrafterClientLauncher

A modern Minecraft Java Edition launcher.

About

CrafterClientLauncher is an independent third-party launcher for Minecraft: Java Edition.

The project aims to provide a modern and user-friendly way to manage and launch Minecraft while keeping the experience simple and accessible.

Authentication

The launcher uses Microsoft account authentication to allow users to access their Minecraft Java Edition accounts.

Users authenticate through Microsoft's official authentication system. The launcher does not ask users to share their Microsoft passwords directly.
